Analyze the invoice text below and extract EVERY line item, including:
- Product/service lines
- Shipping and handling fees
- Administrative fees, surcharges, adjustments
- Discounts (as negative amounts)
- Deposits or advance payments shown

For EACH line item, determine:
1. Description — exactly as shown on invoice
2. Quantity — default to 1 if not shown
3. Unit price — if not shown, use line total
4. Line total — the extended amount for this line (qty × unit price)
5. Tax indicator:
   - "taxable" — line is subject to tax (default assumption)
   - "exempt" — line is explicitly exempt from tax
   - "tax_included" — line total already includes tax (look for "tax incl", "TTC", "taxes incluses", "incl HST")
   - "unclear" — cannot determine tax treatment from the text
6. Tax amount shown — if the invoice shows a per-line tax amount, report it; otherwise null
7. Notes — any observations about this line (e.g., "discount applied", "shipping fee")
8. gl_account — 4-digit Quebec GL account code (see rules below)
9. category — one of: operating_expense, meals, software, telecom, utilities,
   supplies, repairs, capital, bank_fees
10. is_capital — true ONLY if line is equipment / furniture / fixed asset
    AND line_total is greater than $500. Otherwise false.
11. capital_notes — when is_capital=true, suggest the CCA class (e.g.,
    "Class 8 — furniture/equipment", "Class 50 — computers"). Empty otherwise.

GL ACCOUNT RULES (per line, not per invoice):
- 5400 — telecom (phone, mobile, internet, hosting, domain)
- 5410 — utilities (electricity, gas, water)
- 5420 — software / SaaS / app subscriptions / digital licenses
- 5430 — office supplies, small tools, hardware-store items under $500
- 5440 — general operating expense (default when nothing else fits)
- 5500 — bank fees, payment processing fees, interac/credit card fees
- 5640 — meals AND entertainment (restaurants, bars, alcohol) — 50% restriction
- 5750 — repairs and maintenance (vehicle, building, equipment)
- 1820 — equipment / machinery / tools >$500 (capital asset, CCA required)
- 1830 — furniture / fixtures >$500 (capital asset)

CRITICAL TAX EXTRACTION RULE:
- READ the actual tax amounts from the receipt — do NOT calculate them.
- If a line item has no tax shown next to it → gst_amount = 0, qst_amount = 0
- If the receipt shows TPS $0.00 for an item → tax_code = Z, gst_amount = 0
- If total receipt TPS is small relative to total → most items are zero-rated
- NEVER calculate tax_amount = price × rate unless that exact number appears
  on the receipt.
- Zero-rated items (Z): fresh produce, eggs, dairy, meat, bread — tax = 0
- Only set gst_amount > 0 if you can see that exact dollar amount on the
  receipt.

TAX CODE DETERMINATION FROM RECEIPT:
