# Guide de l'employé CPA — OtoCPA

Pour les employés d'un cabinet CPA (reviewer, comptable, junior) qui
n'ont pas le rôle de propriétaire. Si vous êtes propriétaire, voir
[cpa_owner_guide_fr.md](cpa_owner_guide_fr.md).

## 1. Première connexion + 2FA

1. Recevez l'invitation de votre propriétaire de cabinet.
2. Cliquez **Configurer mon compte** et créez votre mot de passe
   (minimum 10 caractères, 1 chiffre, 1 lettre).
3. **Activez l'authentification à deux facteurs** : ajoutez OtoCPA à
   votre application (Google Authenticator, Authy, 1Password) et
   entrez le code à 6 chiffres.
4. Sauvegardez vos **codes de secours** en lieu sûr.

## 2. Mes tâches

Au tableau **Accueil** vous voyez :

- La **file partagée** : tous les documents en attente du cabinet.
- **Mes tâches** : documents qui vous ont été attribués
  spécifiquement par le propriétaire ou un admin.
- **Filtres** : client, statut, période, téléverseur, date.

## 3. Réviser un document

Cliquez sur un document pour ouvrir la vue détaillée :

1. **Image** : zoom, rotation, sélection de zone pour re-OCR.
2. **Champs extraits** : date, fournisseur, montant, TPS, TVQ,
   catégorie. Corrigez en place si besoin.
3. **Notes du client** : commentaire laissé lors du téléversement.
4. **Action** : Approuver, Rejeter, ou Escalader.

## 4. Soumettre pour revue

Si vous êtes bookkeeper junior :

1. Complétez les champs extraits.
2. Cliquez **Soumettre pour revue**.
3. Un reviewer senior recevra le document dans sa file.

## 5. Escalader à un senior

Un cas complexe? Cliquez **Escalader** et ajoutez une note
expliquant la question. Le document passe dans la file des reviewers
seniors avec votre note attachée.

## 6. Outils de flux de travail

- **Approbation en lot** : case à cocher d'en-tête.
- **Recherche globale** : loupe en haut.
- **Raccourcis clavier** : `?` affiche la liste complète.
- **Mode hors-ligne** : les révisions en cours sont sauvegardées
  localement et synchronisées au retour de la connexion.

## Questions fréquentes

**Q : J'ai perdu mon téléphone 2FA.**
R : Utilisez un code de secours OU demandez à votre propriétaire de
réinitialiser votre 2FA.

**Q : Je vois un document d'un autre client par erreur?**
R : Signalez-le immédiatement à votre propriétaire. La portée est
par cabinet; un document hors-cabinet ne devrait jamais apparaître.

## Besoin d'aide

Parlez à votre propriétaire de cabinet, ou écrivez à
